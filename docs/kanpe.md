## 開始前（30分前には始める）

### 1. ネットワーク

- [ ] ハンズオン用ルーター（2.4GHz）の電源を入れる
- [ ] 親機 PC をルーターにつなぐ
- [ ] `ipconfig` で **「Wireless LAN adapter Wi-Fi」の IPv4 アドレス** を確認する（WSL・VPN のアドレスと取り違えない）
  - ルーターで予約した IP と同じか。違ったら、3年生の `secrets.h` に書く値が変わるので注意
- [ ] SSID・パスワード・IP をホワイトボードに書く（パート3のスライド p.30 で使う）
- [ ] 親機 PC のスリープ・画面オフを切る

### 2. Node-RED（親機 PC）

リポジトリ直下で起動する（`logs/` もここにできる）。

```powershell
cd <リポジトリの場所>\handson-2026-m5
git switch develop; git pull
$env:BALLOON_WEB_DIR = "$PWD\web"
node-red "$PWD\node-red\flows.json"
```

- [ ] ファイアウォールの確認が出たら **プライベートネットワーク** で許可
- [ ] プロジェクター側のブラウザで http://localhost:1880/balloon/ を開き、右上が「接続済み」になる → `F11` で全画面
- [ ] エディタ（http://localhost:1880/）は親機 PC の手元の画面で開いておく（パート3で映す）

### 3. 動作確認（講師の CoreS3 で）

- [ ] 講師の CoreS3（完成版）を起動 → 画面の下が `Wi-Fi ○  MQTT ○`、表示画面に自分のマスが出る
- [ ] 吹くとマスの圧力が動く
- [ ] タブ「研究の例：CSV に保存」で「記録を始める」→ 吹く →「記録を止める」→ `logs/` に CSV ができる（実演のリハーサル。できた CSV は消してよい）
- [ ] 表示画面の × で講師のテスト用のマスを消す（または Node-RED の「参加者の一覧を消す」）

### 4. 全員で風船ゲーム（2:20〜2:45）p.49〜50

親機 PC の担当が表示画面のボタンで操作する。

| 操作 | どこで | いつ |
